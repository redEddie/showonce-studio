# ShowOnce Studio 화면·설계 기준

현재 웹앱의 구성과 분위기를 유지하기 위한 간단한 기준입니다. 화면 수정 전에 참고하고,
페이지 역할이나 공통 표현이 바뀌면 이 문서도 함께 갱신합니다. 세부 수치와 동작의 기준은 실제 코드입니다.

## 제품의 역할

사람의 RGB-D 시연을 수집하고, 작업 단계와 객체 간 관계를 검토한 뒤 학습한 정책을 실행기에 연결합니다.
Studio는 시연 분석·검토·배포 UI, `piper-learning`은 학습, `piper-runtime`은 공통 관측·제어를 담당합니다.
물체 에셋 제작은 별도 사전 작업이며, 새 영상 분석에서는 등록된 에셋을 재사용해 위치·자세를 추적합니다.

## 네 페이지

모든 페이지의 상단에 아래 메뉴를 같은 이름·순서로 표시하고 현재 위치를 강조합니다.
하위 메뉴로 두 페이지를 같은 번호에 묶지 않습니다.

| 메뉴 | 경로 | 중심 작업 |
| --- | --- | --- |
| 01 수집 | `/` | 카메라 미리보기, 녹화 시작·종료, 저장 상태, 최근 영상 |
| 02 스테이지 분할 | `/stages` | VLM 자동 분할, 영상·시간축·목록, 경계 편집, 저장·확정 |
| 03 객체 관계 정의 | `/objects` | 참조 에셋 선택, 추적 오버레이, 3D 장면·씬 그래프, 에셋 상세 |
| 04 정책 실행 | `/policies` | SDK 제어, 정책 검증·실행, 명령어/바로 실행 선택, 작업 상태·로그·중단 |

- 페이지를 이동할 때 선택한 영상 ID를 유지하고, 영상 검토 화면 사이에서는 재생 시각도 전달합니다.
- 스테이지 편집은 02에 집중합니다. 03에는 확정한 단계와 현재 관계를 읽기용으로 함께 표시합니다.
- 스테이지 분할과 객체·관계 분석은 독립 작업이며 같은 영상 ID로 연결합니다.
  확정한 스테이지 시각으로 관측 관계를 강제로 맞추지 않습니다.

## 시각적 분위기

밝고 차분한 연구·실험 도구를 지향합니다. 기존 화면과 조화되는 카드·입력·버튼을 재사용합니다.

| 요소 | 기준 |
| --- | --- |
| 배경·헤더 | 밝은 회색 배경, 짙은 남색 헤더 (`#eef1f4`, `#132a3b`) |
| 강조 | 주요 행동은 짙은 녹색, 현재 메뉴·완료 상태는 녹색 계열 (`#28764c`, `#9dd4b0`) |
| 상태 | 준비·완료는 녹색, 주의·불확실은 황색, 오류·중단은 적색. 문구를 함께 표시 |
| 카드 | 흰색 바탕, 얇은 테두리, 부드러운 모서리, 약한 그림자, 일정한 여백 |
| 글자 | 현재 sans-serif 폰트 스택 유지. 제목·본문·보조 설명의 크기와 대비를 구분 |
| 배치 | 영상·3D 결과를 넓게, 관련 입력·편집은 옆이나 아래에 배치 |

색상값은 기준 팔레트입니다. 픽셀 단위 고정보다 전체 일관성과 읽기 쉬운 대비를 우선합니다.
좁은 화면에서는 두 열을 한 열로 바꾸고, 네 메뉴와 주요 버튼에 가로 스크롤 없이 접근할 수 있게 합니다.

## 공통 상호작용

- 상단 메뉴 → 페이지 제목·설명 → 영상/정책 선택 → 주요 작업 → 결과·상태 순서를 유지합니다.
- 주요 작업 버튼과 보조 버튼을 구분하고, 진행 중에는 중복 실행을 막고 현재 단계를 표시합니다.
- 긴 작업은 분석 중/완료/오류를 명확히 구분합니다. 일부 결과가 먼저 보여도 전체 완료로 표시하지 않습니다.
- 초안 저장과 확정을 구분하고, 저장하지 않은 변경을 알립니다. 기존 확정본과 이력을 보존합니다.
- 상세 판정값·JSON·모델 비교·물리 검사 등은 펼쳐보기에 두고 기본 화면은 간결하게 유지합니다.
- 복사용 명령은 필요한 인자만 표시합니다. 웹앱 관리 경로·토큰은 명령창 위 작은 보조 글씨로 분리하고, 명령창을 접거나 닫을 수 있게 합니다.
- 빈 결과·인식 누락·불확실 상태를 숨기거나, 관측이 없는 값을 실제 측정처럼 표시하지 않습니다.

## 영상·3D·그래프

- 원본 영상 시간을 공통 기준으로 삼아 오버레이·3D 객체·씬 그래프를 동기화합니다.
- 에셋을 클릭하면 마우스로 회전·확대·이동하며 메시와 측정 점군을 비교할 수 있게 합니다.
- 3D 조작은 Three.js/OrbitControls, 그래프는 ECharts를 사용합니다. 기존 라이브러리와 표현을 재사용합니다.
- 단위와 좌표계를 표시하고, 3D 검토 격자는 작은 격자 10mm·큰 격자 50mm를 기준으로 합니다.
- 영상 포즈 재생, 물리 시뮬레이션, 가짜 로봇 mock, 실제 로봇 실행을 구분해 표시합니다.
  영상의 접촉·파지 관계 추정과 정책 추론 검증을 물리 실측이나 실기 성공으로 표현하지 않습니다.

## 구현과 변경 확인

화면 파일은 `src/showonce_studio/web/`에 있습니다. 공통 메뉴와 작업 화면 스타일은
네 HTML 및 `showonce_workflow.css`, 페이지 동작은 대응하는 JavaScript를 함께 확인합니다.
웹/API와 카메라·모델 분석·정책 실행 worker는 분리하며, 단순 페이지 이동으로 모델을 다시 로드하지 않습니다.
04는 기본적으로 명령어를 보여줍니다. 사용자가 바로 실행을 선택해 버튼을 누르면 별도 worker로 실행합니다.
정책 중단(Ctrl+C/SIGINT)과 SDK Stop(감쇠 전자정지)을 구분하고, 활성 작업과 중단 버튼을 쉽게 찾을 수 있게 합니다.
탭 새로고침은 작업을 중단하지 않으며 작업 ID로 복구합니다. 정책의 실행 시간·남은 시간·로그·종료 결과를 표시합니다.
페이지 로드·상태 폴링은 작업 기록·실시간 인식 출력·카메라 프리뷰만 읽고, SDK 상태 조회는 사용자의 명시적 버튼 조작으로 실행합니다.
수동 TCP는 명시적 연결 후 XYZ를 누르는 동안 이동하고 RPY는 ±90° 버튼으로 조작합니다.
현재 수동 제어 개선은 보류합니다. 패널은 기본 접힘으로 두고 코드를 보존하며,
외부 프로젝트를 검토한 뒤 개선합니다. 패널을 닫으면 수동 연결도 종료합니다.
방향별 도달 가능 여부·불가 이유를 표시하며 피드백이 오래되면 조작 버튼을 비활성화합니다.
현재값·목표값과 mm/도 단위를 구별하고, 기본 그리퍼 force 0.5를 유지합니다.
팔 풀기는 TCP 위치 고정·방향 변경 허용으로 표시합니다. 경로만 검사와 실제 실행을 구별하고,
기준 TCP·최대 위치 편차·관절 여유 및 상세 경유점을 확인할 수 있게 합니다.

UI 변경 후 네 메뉴 이동, 선택 영상·재생 시각 유지, 저장/확정 표시, 로딩·오류·빈 상태,
영상/3D/그래프 연동과 좁은 화면을 확인합니다. 테스트와 리뷰에는 합성 예제를 사용할 수 있습니다.

## 04 실시간 실행 화면

선정 정책 다음에는 실시간 인식 영상과 실행 설정을 나란히 둡니다. 인식 노드가 없을 때는
촬영 원본임을 표시하고 SAM 결과로 표현하지 않습니다. 큐브/그릇의 실제 관측 시각을 유지하여
최신 관측·관측 지연·현재 관측 없음으로 구분합니다. 정책이 받은 좌표와 저장 위치/파지 추정의
출처는 카메라 관측과 분리합니다. 이전 실행 입력에는 이전 기록이라는 표시를 유지합니다.

생성된 정책 명령은 정책 실행 버튼 바로 아래, SDK 명령은 SDK 버튼 아래에 표시합니다.
보정·인식 폴더가 연결되지 않으면 자리표시자 명령을 복사할 수 없게 하고 이유를 같은 위치에
표시합니다. 선택값을 바꾸면 이전 명령의 복사를 해제하며 다시 생성하도록 안내합니다.
영상 갱신이 끊기면 이전 프레임을 계속 최신 영상처럼 보여주지 않습니다.

실시간 인식이 구성된 장비는 촬영 노드의 RGB-D를 지속 인식 worker와 공유합니다.
촬영/인식을 수동 전환하도록 안내하지 않으며, 웹 새로고침이나 정책 선택 변경이 SAM 재로딩을 유발하지 않게 합니다.

04의 XY 지도는 기존 ECharts로 그립니다. 로봇 베이스를 원점으로 위쪽 +X/왼쪽 +Y를 유지하고,
10mm 작은 격자/50mm 큰 격자, 원점과 모든 표시 궤적을 포함하는 동일 축척을 사용합니다.
카메라 관측은 실선, 정책 입력/피드백 FK TCP는 점선으로 구별합니다. 과거 실행은 과거 기록으로 표시하고
궤적 지우기는 화면만 초기화하며 실행 로그를 삭제하지 않습니다.

실제 구동에는 `실제 로봇 실행 준비`로 직접 실행/run을 선택한 뒤 `실제 로봇 실행 (run)`을 누릅니다.
준비 버튼 자체는 프로세스나 로봇 명령을 보내지 않습니다. 실제 동작 버튼은 계산/명령 생성과 다른 문구·색으로 표시합니다.

시작 자세 A로 이동하는 Home 버튼은 실행 순서 안내 안에서 Enable과 나란히 제공합니다.
명령 보기/직접 실행을 따르며, 명령창도 해당 버튼 아래에 표시합니다. 이동 중 상태·중복 실행 비활성화·Home 중단을 함께 제공합니다.
