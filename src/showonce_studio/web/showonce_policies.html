Enable은 현재 그리퍼 폭을 유지하며 force 0.5로 활성화합니다. Disable은 모터 전원을 해제합니다. SDK Stop은 감쇠 전자정지이며 정책 중단과 다릅니다. Reset은 정지·오류 복구 요청입니다.
SDK 상태는 조회·명령 실행 후 표시됩니다. 이 화면을 여는 것만으로 SDK에 연결하지 않습니다.

작업은 별도 프로세스로 실행되고 새로고침 후에도 상태를 확인할 수 있습니다.
선택한 작업의 로그·결과
정책 중단은 해당 작업에 SIGINT를 보내 감속 종료를 요청합니다. 탭을 닫아도 작업은 계속되며 정책은 설정한 실행 시간 후 종료합니다. SDK Stop·Disable을 직접 실행하면 관리 중인 같은 채널의 정책 전송을 먼저 종료합니다.
